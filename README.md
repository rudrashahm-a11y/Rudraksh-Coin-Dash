# 🎮 Coin Dash

A cute, fast-paced browser arcade game built with **HTML5 Canvas, CSS, and vanilla JavaScript**.

## Play

Once GitHub Pages is enabled, your game will be available at:

`https://YOUR-USERNAME.github.io/coin-dash/`

No server, database, build step, framework, or paid hosting is required.

## Features

- 🪙 Collect coins and bonus coins
- 💎 Collect gems
- ⚡ Grab a speed boost
- 👾 Avoid slimes, bats, and wooden barriers
- ❤️ 3 lives
- ⏱️ 60-second challenge
- 🏆 Best score saved in the browser
- 📱 Responsive mobile controls
- 🖥️ Keyboard controls
- 🎨 Lightweight original Canvas artwork
- 🚀 GitHub Pages ready

## Controls

### Desktop
- **Left / A** — Move left
- **Right / D** — Move right
- **Up / W / Space** — Jump

### Mobile
Use the on-screen **←**, **JUMP**, and **→** buttons.

## Run locally

You can simply open `index.html` in a modern browser.

For a local development server, for example:

```bash
python -m http.server 8000
```

Then open:

`http://localhost:8000`

## Publish with GitHub Pages

1. Create a **public** GitHub repository named `coin-dash`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Click **Save**.
7. Wait for GitHub Pages to deploy.
8. Open `https://YOUR-USERNAME.github.io/coin-dash/`.

### Important

Keep `index.html` in the repository root. GitHub Pages serves that file as the game's entry point.
